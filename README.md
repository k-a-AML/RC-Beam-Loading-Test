# Real-Time FEM RC Beam Simulator: Concrete Cracking & Rebar Plasticity

鉄筋コンクリート（RC）梁 リアルタイム弾塑性・ひび割れ進展シミュレータ (デモ・スタンドアロン実行版)

## 1. 概要 (Overview)

本アプリケーションは、鉄筋コンクリート（RC）矩形梁を対象とした**3次元固体コンクリート損傷塑性＋1次元埋め込み鉄筋弾塑性の非線形連成FEM解析**をリアルタイムに実行・可視化する教育・研究用シミュレータです。

C++ネイティブ計算エンジン（Eigen）による増分Newton-Raphson法ソルバーと、Unity URPによる高品位プロシージャル・シェーディング技術を融合しています。

画面上のボタン操作による強制変位制御を行いながら、以下の力学現象をリアルタイムに観察・追体験できます：
* **未ひび割れ弾性域:** い初期曲げ剛性の発現
* **初生ひび割れの発生:** 下端がひび割れ応力に達した瞬間のクラック発生と剛性低下
* **応力再配分と鉄筋降伏:** ひび割れ開口に伴う引張力の中央主筋へのダイレクトな集中・先行降伏、および追従する全主筋の降伏
* **塑性棚（プラトー）:** 全主筋降伏後のほぼ水平な塑性流動域の形成
* **除荷と残留変形:** 除荷時の剛性低下、残留たわみの保持、およびゼロ反力停止制御（Unloading Protection）

> **【デモ版について】**  
> 本配布パッケージはスタンドアロンの**機能検証・可視化デモ版**です。内部のFEMソルバーおよびメッシュ生成システムは、Unityエディタ開発環境上ではInspectorから任意の部材断面寸法・スパン長・鉄筋径・本数・スターラップピッチへ自由に変更可能ですが、本実行ファイル版では安定動作および実験比較のため**標準諸元（幅200mm × 高さ350mm, スパン3.0m, 主筋3-D19）に固定**されています。

## 2. 実験仕様・標準諸元 (Specifications)

起動時のシーンにあらかじめ設定・固定されている標準諸元です（載荷実験の標準的ベンチマーク条件）。

| 項目 | 設定値・仕様 | 備考 |
| :--- | :--- | :--- |
| **対象部材** | **RC矩形梁** ($B = 200\,\mathrm{mm},\, D = 350\,\mathrm{mm}$) | 有効高さ $d = 300\,\mathrm{mm}$, かぶり厚 $d_c = 40\,\mathrm{mm}$（端部かぶり $40\,\mathrm{mm}$） |
| **梁スパン長** | 支点間 $L = 3.0\,\mathrm{m}$（張出 $0.15\,\mathrm{m}$ × 2, 全長 $3.3\,\mathrm{m}$） | 3次元Hex8ソリッド ＋ 1Dトラス連成要素 |
| **載荷方式** | **スパン3等分点 2点曲げ載荷（4点曲げ試験）** | $z = 1.0\,\mathrm{m}$ ($L/3$), $z = 2.0\,\mathrm{m}$ ($2L/3$) の上面鉛直変位制御 |
| **配筋構成** | **下端引張主筋:** 3-D19 ($A_s = 859.5\,\mathrm{mm}^2$)<br>**上端圧縮主筋:** 2-D13 ($A_s' = 253.4\,\mathrm{mm}^2$)<br>**せん断補強筋:** D10 @ 100mm or 300mm ピッチ | 引張鉄筋比 $p_t = 1.43\%$<br>せん断余裕度 100mmピッチ：約2.31倍（曲げ降伏先行） 300mmピッチ：1.23倍（曲げ降伏後せん断破壊）|
| **コンクリート物性** | $F_c = 27\,\mathrm{MPa},\, f_t = 2.91\,\mathrm{MPa},\, E_c = 28.0\,\mathrm{GPa},\, \nu = 0.20$ | Rankine引張軟化 ＋ Drucker-Prager圧縮降伏 |
| **鉄筋材料物性** | $f_y = 345\,\mathrm{MPa}$ (SD345), $E_s = 205\,\mathrm{GPa}, H' = 2.05\,\mathrm{GPa}$ | バイリニア等方硬化モデル |
| **せん断補正** | 選択低減積分（B-bar / Mean Strain法） | Hex8要素特有のせん断ロッキング（寄生せん断）を解消 |

## 3. 起動方法と動作要件 (Quick Start & Requirements)

### 3.1 動作要件
* **対応OS:** Windows 10 / 11 (64-bit)
* **グラフィックス:** Direct3D 11 / 12 対応 GPU

### 3.2 必須ランタイム
本シミュレータの非線形計算エンジン（C++ DLL）を実行するためには、PCに **Microsoft Visual C++ 再頒布可能パッケージ (x64)** がインストールされている必要があります。

* **公式ダウンロードリンク:**  
  [Microsoft Visual C++ 再頒布可能パッケージ 最新版 (x64)](https://learn.microsoft.com/ja-jp/cpp/windows/latest-supported-vc-redist)  
  （リンク先から `vc_redist.x64.exe` を入手してインストールしてください）

※ 起動時に「DLLが見つかりません」などのエラーダイアログが出る場合は、上記ランタイムを導入してください。

### 3.3 実行手順
1. ダウンロードした ZIP ファイルを右クリックし、**「すべて展開（解凍）」** します。
2. 展開されたフォルダ内にある **`RC-Beam-Loading-Test.exe`** をダブルクリックして起動します。

> **【注意】**  
> ZIP ファイルを展開せずに直接開いて実行すると、外部DLL（`FemSolver.dll`）が正常にリンクされず起動に失敗します。必ず展開を行ってから実行してください。また、フォルダ内の構成ファイルやフォルダ名を変更・削除しないでください。

## 4. 操作方法 (Controls)

### 4.1 マウス・視点操作 (Camera Controls)
* **視点の回転 (Orbit):** `マウス右ドラッグ`
* **視点の平行移動 (Pan):** `Shift` + `マウス右ドラッグ` または `マウス中ボタン (ホイールクリック) ドラッグ`
* **ズーム (Zoom):** `マウスホイール回転`
* **梁全体に自動収束 (Fit View):** キーボード `F` キー
* **視点初期化 (Reset View):** キーボード `R` キー

#### 【キーボード プリセット視点切替】
* `[1]` **真上見下ろし (Top View):** 梁上面のひび割れや純曲げ区間を確認
* `[2]` **側面右 (Side View +X):** ひび割れの立ち上がり・中立軸の推移を真横から観察
* `[3]` **側面左 (Side View -X):** 反対側面からの観察
* `[4]` `[5]` **端面見通し (End View ±Z):** 梁の鉛直たわみと断面の変形状態を見通す

---

### 4.2 画面UI・シミュレーション操作 (GUI Controls)
画面左上のメイン操作パネルおよびリアルタイム $P-\delta$ (荷重-たわみ) グラフから直感的に操作します。

1. **強制変位制御ボタン (`-0.5mm`, `-0.1mm`, `+0.1mm`, `+0.5mm`):**
   * 油圧アクチュエータによる押し込み量（たわみ目標値）を段階的に増減させます。
   * **載荷 (Loading):** `+0.1mm` / `+0.5mm` をクリックして押し込みを進めます。
   * **除荷 (Unloading):** `-0.1mm` / `-0.5mm` をクリックしてジャッキを戻します。
2. **除荷時ゼロ反力停止制御 (Unloading Protection):**
   * 降伏域まで変形させた後に除荷を進めると、反力が $0\,\mathrm{kN}$ に到達した時点で自動的に「STATUS: UNLOAD ZERO」となり停止ロックがかかります（梁を上向きに引っ張り上げる非現実的な負反力を防止）。
   * ロック状態から再び `+0.1mm` を押すと即座に再載荷（Reloading）へ移行します。
3. **Display Field (コンター表示項目切替ボタン):**
   * **選択中の項目は文字がオレンジ色（太字）にハイライト**されます。
     * **σ1 (引張):** 最大主引張応力（コンクリート引張破壊指標。引張強度 $f_t = 2.91\,\mathrm{MPa}$ 基準）
     * **σ3 (圧縮):** 最小主圧縮応力（コンクリート圧縮圧壊指標。圧縮強度 $F_c = 27\,\mathrm{MPa}$ 基準）
     * **鉄筋(PEEQ):** 等価塑性ひずみ（主筋の塑性化・降伏度合いを鮮やかに表示）
     * **コンクリ(Dt):** コンクリート引張ひび割れ損傷度 $D_t$（0.0:健全 〜 1.0:完全開口）
4. **Contour 切替ボタン (`Contour: [ ON / OFF ]`):**
   * 応力コンター表示と、写実的な打ち放しコンクリート肌／スチール地肌のPBR表示を切り替えます。
   * ※コンターOFF時は鉄筋の降伏発光（Yield Glow）も自動消灯し、自然な鋼材色で表示されます。
5. **Cracks 切替ボタン (`Cracks: [ ON / OFF ]`):**
   * 梁表面の離散ひび割れ線・透過貫通スリットの描画有効/無効を切り替えます。
6. **不透過率スライダ (`X-Ray Alpha`):**
   * コンクリート外皮の透明度を調整します（値を下げると半透明になり、内部の配筋ケージの応力状態が透視可能になります）。
7. **Reset State ボタン:**
   * 塑性ひずみ履歴・ひび割れ履歴・残留変形を完全初期化し、初期健全状態へ戻します（過去の $P-\delta$ 曲線は薄いグレーの履歴線として保持されます）。

---

### 4.3 実験室環境・治具トグル (画面左下)
* **門型フレーム & ジャッキ表示:** 実験室門型フレームおよび油圧シリンダーロッドの表示切替（ピストンは梁天面の押し込みにリアルタイム追従します）。
* **変位計スタンド表示:** 梁下端の接触型変位計（ダイヤルゲージ）の表示切替（プローブは梁底面に接触追従し、貫通防止クリッピングが働きます）。
* **初期位置モデル(半透明)表示:** 変形前の梁形状（ゴーストメッシュ）を半透明表示し、現在のたわみ量・永久変形量を直感的に比較対照できます。
